Canlı yazışma paneli için Firebase

Ziyaretçi mesajlarını arka planda anlık görmek için ücretsiz Firebase Realtime Database gerekir.

  1. Firebase kurulumunu tamamla

    Realtime Database + web app config + firebase-config.js doldurulmalı.

  2. Kuralları güncelle

    database.rules.json içeriğini Rules’a yapıştır → Publish. Admin mesajı için admin who değeri gerekir.
