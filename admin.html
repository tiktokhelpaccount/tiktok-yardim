Canlı yazışma paneli için Firebase

Ziyaretçi mesajlarını arka planda anlık görmek için ücretsiz Firebase Realtime Database gerekir. Aşağıdaki adımları bitirince bu sayfa panel olur.

  1. Firebase projesi oluştur

    console.firebase.google.com → “Add project” → proje adı ver → devam et.

  2. Realtime Database aç

    Build → Realtime Database → Create Database → konumu seç → şimdilik Start in test mode deyin.

  3. Kuralları yapıştır

    Realtime Database → Rules sekmesine git. Projede database.rules.json içeriğini yapıştır → Publish.

  4. Web uygulaması ekle

    Project Overview → </> Web → uygulama adı → Register. Çıkan firebaseConfig değerlerini kopyala.

  5. Config dosyasını doldur

    Bilgisayarında firebase-config.js dosyasını aç:

    • enabled: true yap
    • adminPassword değerini güçlü bir şifre yap
    • firebase: { ... } alanlarını konsoldaki değerlerle doldur (databaseURL önemli)
  6. GitHub’a yükle

    Değişiklikleri commit + push et. Birkaç dakika sonra site güncellenir. Bu sayfayı yenile, şifrenle gir.
